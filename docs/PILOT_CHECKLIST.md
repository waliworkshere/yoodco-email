# Pilot checklist (Yood)

| | Step | Who |
|---|---|---|
| 1 | Sign in at https://yoodco-email.vercel.app with the admin account and change its password (Settings → Your password). Add Lionel and Pauline under Settings → Team. | Salman |
| 2 | Each of the 7 yood.ai mailboxes: turn on 2-Step Verification, then create an app password (myaccount.google.com → Security → App passwords, name it "Yood Outreach"). The Workspace admin must allow app passwords. | Lionel / Yood IT |
| 3 | Mailboxes → Connect → "Enter details": pick "Google Workspace / Gmail (app password)", paste the address and app password. Repeat for all 7. Check the domain shows SPF, DKIM and DMARC. | Salman |
| 4 | Settings → Zoom: create the Zoom app, save its ID and secret, press Connect Zoom (signed in as the person taking the calls). | Lionel (5 min) |
| 5 | Campaign "Yood · Sequence 1 (pilot)" → Settings → Meetings: who takes the meetings, Video = Zoom (or a fixed link). | Salman |
| 6 | Start test run, check the emails, booking link and invite in the test inbox. Send a test to yourself from each mailbox. | Salman, Lionel approves |
| 7 | Test & launch → Go live. The GitHub "Sender" workflow keeps it sending 9:00–17:00 Central, weekdays. | Salman |

Sending: 20 an hour, random 90–270 s gaps, Email 2 three days and Email 3 four days later, stops on reply.
Results: Overview, the campaign's Replies tab, and Meetings (mark each call Held / No-show).
